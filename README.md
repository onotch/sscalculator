# Shutter Speed Calculator

Calculate shutter speeds with ND filters — quickly and accurately.

This app is a simple calculation tool designed to instantly determine the correct shutter speed when shooting with ND filters.

By selecting your normal shutter speed and the ND filter strength, the app automatically calculates the required shutter speed with the filter attached.
Even when using multiple ND filters stacked together, it accurately accounts for the combined light reduction to provide the correct shutter speed.
Complex calculations are no longer necessary for long exposures or slow-shutter shooting in daylight.

The app can also reverse-calculate the original shutter speed from a shutter speed taken with an ND filter applied.
This is useful not only for single ND filters, but also for checking stacked filter settings and reviewing exposure conditions when reshooting.

## Key Features

- Automatically calculates shutter speed when using ND filters
- Supports shutter speed calculation for stacked ND filters
- Reverse calculation from ND-applied shutter speed to the original value
- Timer feature that counts down the calculated shutter speed duration
- Intuitive, clean, and distraction-free interface
- Ideal for landscapes, waterscapes, and long-exposure photography
